## 一条主线

本章讲的是**智能体的互联互通**，三个协议各管一段：

> **MCP**（智能体 ↔ 工具：`list_tools` 发现能力，`call_tool` 结构化调用——像 USB 接口，插上即用）
> **A2A**（智能体 ↔ 智能体：Agent Card 亮明身份，`@skill` 暴露技能，`execute_skill` 用自然语言对话——像同事间打电话）
> **ANP**（智能体 ↔ 网络：`register_service` 登记，`discover_service` 检索，metadata 决定选谁——像行业黄页）

三者不是竞争而是分层：**ANP 找到人，A2A 跟他谈，他自己再用 MCP 干活**。`01_TestConnect.py` 开篇 25 行给三个协议各拍一张证件照，`12_ANPTaskDistribution.py` 和 `14_weather_agent.py` 则在结尾把协议塞回智能体手里——绕了一整章，落点仍是第四章那条铁律的协议版：**接口定契约（schema / 技能名 / metadata），代码做解析，两头严丝合缝**。

> 前置阅读：chapter4 的讲解（`code/chapter4/讲解/`）解释了单个智能体如何思考与用工具；本章解决的是"很多个智能体和很多种工具"如何互相找到并说上话。
