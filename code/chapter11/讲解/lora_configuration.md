# 03_lora_configuration.py 剥洋葱式讲解

> 源文件：`code/chapter11/03_lora_configuration.py`（301 行）
> 一句话概括：**参数高效微调的"省钱指南"——冻结整个大模型，只在注意力层旁边挂两块小小的低秩矩阵，用不到 1% 的可训练参数完成微调。**

---

## 🧅 第一层（最外层）：这个文件在干什么？

完整微调一个 0.5B 模型要 ~14GB 显存（第 129-140 行的对比数据）——消费级显卡直接出局。LoRA（Low-Rank Adaptation）把这个门槛砍到 ~4GB，训练快 2-3 倍，训练完的"模型文件"只有 ~10MB。

这个文件不跑训练（贵的操作照例注释掉了），而是集中回答配置问题：`lora_r` 和 `lora_alpha` 怎么选？LoRA 注入哪些层？什么场景该用什么配置？在本章语境下答案很直接——**没有 LoRA，后面 SFT 和 GRPO 的一切实验在单卡上都跑不起来**。

---

## 🧅 第二层：LoRA 的原理与两个旋钮（第 34-53 行）

```python
config = {
    ...
    "use_lora": True,           # 启用LoRA
    "lora_r": 16,               # LoRA秩(rank)
    "lora_alpha": 32,           # 缩放因子(通常是r的2倍)
}
```

LoRA 的核心想法：微调时权重的变化量 ΔW 其实是"低秩"的（信息量远小于矩阵尺寸）。于是不去动原权重 W，而是在旁边并联一条捷径：

```
输出 = W·x + (alpha/r) · B·A·x
       ↑冻结        ↑ 只训练 A(r×d) 和 B(d×r) 两块小矩阵
```

两个旋钮的含义：

- **`lora_r`（秩）**：小矩阵的"宽度"，直接决定可训练参数量和表达能力。示例 2（第 75-91 行）给出量级感受：r=8 约 16K 参数、r=16 约 32K、r=32 约 65K——参数量随 r 线性翻倍。
- **`lora_alpha`（缩放因子）**：实际缩放是 `alpha/r`，控制 LoRA 分支对输出的影响强度。示例 5（第 244-249 行）点破了行规：**`lora_alpha = 2 × lora_r`**——这样缩放恒为 2，调 r 时不用重新调学习率。文件里所有配置都严格遵守：8/16、16/32、32/64。

## 🧅 第三层：注入哪些层？（第 53 行）

```python
print(f"  目标模块: ['q_proj', 'v_proj'] (默认)")
```

一行打印，藏着 LoRA 论文的关键实验结论。Transformer 每层注意力有四个投影矩阵（Q/K/V/O），再加 FFN 的几个大矩阵——全挂 LoRA 参数量就上去了。默认**只挂 `q_proj`（query 投影）和 `v_proj`（value 投影）**：

- **Q 决定"关注哪里"**——微调它能改变模型的注意力分配模式；
- **V 决定"取出什么信息"**——微调它能改变提取的内容表示；
- K 和 Q 在注意力打分中是对称的，挂一个就够；O 和 FFN 的收益相对边际。

LoRA 原论文的消融实验表明：同等参数预算下，`q_proj + v_proj` 的组合性价比最高。这就是"10MB 模型文件"的来源——保存时只存这些小矩阵，原模型一个字节都不用动；推理时既可以合并回原权重（零延迟开销），也可以像插件一样按任务热插拔。

## 🧅 洋葱心：三档配置的取舍表（第 156-197 行）

示例 4 给出的三档配置，是全章实验的"档位表"：

```python
# 快速实验:  max_samples=100,  epochs=1, batch=8, r=8,  alpha=16
# 标准训练:  max_samples=1000, epochs=3, batch=4, r=16, alpha=32, lr=5e-5
# 高质量:    max_samples=None, epochs=5, batch=2, r=32, alpha=64, lr=3e-5
```

三行配置里藏着一组**联动规律**，而不是孤立的参数：

1. **数据越多 → r 越大**：100 个样本喂不饱 r=32 的容量（白白过拟合），全量 7500 样本才配得上大秩；
2. **r 越大 → batch 越小**：可训练参数多了，显存得从 batch 里省回来；
3. **训练越久 → 学习率越保守**（5e-5 → 3e-5）：跑 5 个 epoch 还用大学习率，后期容易在最优点附近震荡。

调参不是逐个旋钮拧，而是**整档位切换**——这三档就是现成的档位。
