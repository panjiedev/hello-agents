# Chapter 8 代码剥洋葱讲解

对 `code/chapter8/` 下十一个代码文件的逐层拆解。本章主题是**记忆与 RAG**——给智能体装上两种"记性"：记住自己经历的 Memory 系统，和记住外部知识的 RAG 系统。十一个文件按主题归为四篇，每篇都采用"剥洋葱"结构：从最外层的**这组文件在干什么**开始，一层层剥到最核心的**那几行关键代码**，最后回到全局，说明它在本章版图中的位置。

## 一条主线

本章讲的是**如何让智能体有记性**。答案是两套系统、一个协议：

> **Memory**（自己的经历：提问、学习、笔记——"我做过什么"）
> **RAG**（世界的知识：文档、手册、论文——"世界是什么"）
> 两者底层是同一套向量思想的两次落地：**编码 → 存储 → 相似度检索**。

贯穿十一个文件的一条工程铁律：**统一的字典协议 `run({"action": ..., ...})` 是一切能力的总闸**——MemoryTool 的 add/search/forget/consolidate、RAGTool 的 add_document/search/ask，全部收敛于同一个调用形状。正因如此，第 08 篇里两个工具才能被 ToolRegistry 一视同仁地注册，第 11 篇里才能在一次 `ask` 中三次 `run` 编排出"记问题 → 查知识 → 记经历"的完整闭环。

四种记忆的分工值得反复咀嚼：**工作记忆是加工台（快、小、易逝），情景记忆是日记本（何时何地发生过什么），语义记忆是教科书（概念与关系），感知记忆是相册（多模态素材）**；而记忆巩固机制（`consolidate` + `importance_threshold`）就是把日记提炼成教科书的那支笔。
